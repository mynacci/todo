# 할 일 관리 앱 PRD

## 1. Why - 목적
- 할 일을 상태(todo/doing/done)로 시각적으로 관리
- 일일 할 일이 주간 계획과 1년 목표에 어떻게 기여하는지 구조적으로 연결
- 주간 진행률을 수동 입력 없이 자동 확인
- 장기 목표와 일상 실행 간 단절 해소

## 2. Who - 타깃 사용자
- 1년 단위 목표를 세우고 일상에서 실행하려는 개인
- 학생, 직장인, 자기계발 목표를 가진 사용자
- 칸반 스타일(드래그 앤 드롭) 관리 방식을 선호하는 사용자
- Pain Point
  - 목표와 일일 할 일이 분리되어 있음
  - 진행 상황 파악을 위해 직접 계산·정리해야 함

## 3. User Flow
- 1년 목표 생성
  - 목표 제목 입력 → 저장
- 주간 계획 생성
  - 주차 선택 → 계획 제목 입력 → 상위 1년 목표 연결 → 저장
- 할 일 생성
  - 제목 입력 → 날짜 지정 → 상위 주간 계획 연결 → 상태 기본값 todo로 저장
- 할 일 상태 변경
  - 칸반 보드(todo / doing / done) 진입 → 카드를 다른 컬럼으로 드래그 앤 드롭 → 상태 즉시 저장
- 진행률 확인
  - 주간 계획 상세 진입 → 완료율 자동 표시
  - 1년 목표 상세 진입 → 연결된 주간 계획 및 진행률 확인
- 할 일 수정/삭제
  - 카드 선택 → 수정 또는 삭제 → (삭제 시) 확인 후 반영

## 4. 기능 요구 사항

### P0 - 핵심 기능
- 할 일 CRUD
  - 생성: 제목(필수), 날짜, 상위 주간 계획
  - 조회: 일일 / 주간 / 상태별 목록
  - 수정: 제목, 날짜, 상태, 상위 주간 계획 변경
  - 삭제: 삭제 전 확인 팝업
- 상태 관리
  - 상태 값: todo / doing / done
  - 신규 생성 시 기본값: todo
- 드래그 앤 드롭 상태 변경
  - 칸반 3컬럼(todo / doing / done)
  - 카드를 컬럼 간 이동 시 상태 즉시 변경 및 저장
  - 변경 즉시 진행률 반영
- 기간 구조
  - 일일: 할 일 단위
  - 주간: 주간 계획 단위 (주 시작일~종료일)
  - 1년: 연간 목표 단위
  - 주간 계획 CRUD, 1년 목표 CRUD
- 구조 연결
  - 할 일 → 주간 계획 (N:1)
  - 주간 계획 → 1년 목표 (N:1)
  - 상위 항목 삭제 시 처리 정책: 하위 항목 연결 해제 또는 삭제 여부 선택
- 주간 진행률 자동 반영
  - 산식: 완료(done) 할 일 수 ÷ 주간 계획 내 전체 할 일 수 × 100
  - 할 일 생성/삭제/상태 변경 시 자동 재계산
  - 할 일이 0개인 경우 0%로 표시

### P1 - 추가 기능
- 1년 목표 진행률
  - 연결된 주간 계획 진행률 기반 자동 집계
- 필터/정렬
  - 날짜, 상태, 주간 계획, 1년 목표 기준
- 검색
  - 할 일 제목 검색
- 마감 임박/지연 표시
  - 날짜 지난 미완료 할 일 강조
- 미완료 할 일 이월
  - 주간 종료 시 다음 주 계획으로 이동
- 주간 회고
  - 주간 종료 시 완료율 요약 표시
- 알림
  - 할 일 마감 알림
